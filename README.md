# OUTBREAK LAB Web Edition

OUTBREAK LAB es un laboratorio educativo de modelos matemáticos sobre datos históricos de COVID-19. Esta edición está construida con HTML, CSS y JavaScript y funciona como un sitio estático, sin backend.

## Explorar

La aplicación incluye análisis de datos de España, modelos y métricas, escenarios matemáticos hipotéticos, un mapa histórico mundial y un simulador de distribución por ciudades. Los escenarios no son predicciones sanitarias ni describen rutas reales de contagio.

## Fuentes y atribuciones

- Datos de COVID-19: COVID-19 Data Repository by the Center for Systems Science and Engineering (CSSE) at Johns Hopkins University, licencia CC BY 4.0: https://github.com/CSSEGISandData/COVID-19
